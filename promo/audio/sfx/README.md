# Downloaded sound effects

Put sound files here and rerun `node promo/audio/mix.mjs`. A file's name says what it replaces:

| Name starts with | Used for |
| --- | --- |
| `whoosh` | every scene change (8 of them); several files take turns, e.g. `whoosh-1.mp3`, `whoosh-2.mp3` |
| `impact` | a soft cinematic hit on "Meet Lunch Board" |
| `pop` | thought bubbles, answer clouds and diagram boxes |
| `click` | the tap on "Complete my order" |
| `chime` | "Order placed" and "about 5 min" |
| `ding` | each by-hand order turning "Placed" |

Anything missing stays synthesised. mp3, wav, ogg, m4a, flac and aiff all work. Whooshes and the
impact are lined up on their loudest moment; the rest start on their first sound.
Pixabay sounds are free to use in the video without credit (Pixabay Content License).
